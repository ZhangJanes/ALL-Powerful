## 1. 整体架构

```
┌──────────────┐     HTTP + JWT      ┌─────────────────────┐
│   Frontend   │ ──────────────────► │  Spring Boot 后端    │
│  Vue3 + Vite │   /api/*            │  端口 8080           │
└──────────────┘                     └──────────┬──────────┘
                                                │
                    ┌───────────────────────────┼───────────────────────────┐
                    │                           │                           │
                    ▼                           ▼                           ▼
             ┌────────────┐              ┌────────────┐              ┌────────────┐
             │   MySQL    │              │   Redis    │              │   Kafka    │
             │  持久化主库 │              │   缓存     │              │  异步事件   │
             │  端口 3306 │              │  端口 6379 │              │  端口 9092 │
             └────────────┘              └────────────┘              └────────────┘
```

**数据持久化说明：**

| 存储 | 持久化什么 | 是否必须 |
|------|-----------|----------|
| **MySQL** | 用户、备忘录、出行、照片元数据等 | ✅ 核心，必须启动 |
| **Redis** | 消息接口短期缓存 | 建议启动 |
| **Kafka** | 提醒变更、上传通知等事件 | 建议启动 |
| **本地 mock** | 前端 `app.ts` 里部分模块的演示数据 | ❌ 非持久化，重启丢失 |

> **重要：** 用户、备忘录、出行、照片库等已通过后端 API 写入 MySQL。账本、习惯、灵感等模块目前仍主要使用前端 mock 数据，尚未全部对接后端。

## 4. 创建并启动数据库

本项目 **不需要手动写 SQL 建库建表**。流程是：

1. Docker 启动 MySQL 容器，自动创建数据库 `all_powerful`
2. 后端首次启动时，Flyway 自动执行迁移脚本建表

### 4.1 启动基础设施

```bash
cd /Users/huifeidexitieshi/Desktop/Home-App/ALL-Powerful/Backend
docker compose up -d
```

第一次会下载镜像，可能需要 5～15 分钟。

### 4.2 查看容器状态

```bash
docker compose ps
```

期望 4 个容器均为 `running`：

| 容器名 | 端口 | 作用 |
|--------|------|------|
| all-powerful-mysql | 3306 | **MySQL 数据库（持久化核心）** |
| all-powerful-redis | 6379 | Redis 缓存 |
| all-powerful-zookeeper | 2181 | Kafka 依赖 |
| all-powerful-kafka | 9092 | 消息队列 |

MySQL 刚启动时可能是 `starting`，等 30～60 秒后再查，最好变为 `healthy`。

### 4.3 确认数据库已创建

```bash
docker exec -it all-powerful-mysql mysql -uroot -proot -e "SHOW DATABASES;"
```

应能看到 `all_powerful`。

### 4.4 配置环境变量

```bash
cd Backend
cp .env.example .env
```

`.env` 默认内容（本地一般不用改）：

```env
DB_HOST=127.0.0.1
DB_PORT=3306
DB_NAME=all_powerful
DB_USER=root
DB_PASSWORD=root

REDIS_HOST=127.0.0.1
REDIS_PORT=6379

KAFKA_BOOTSTRAP_SERVERS=127.0.0.1:9092

APP_JWT_SECRET=ChangeThisToStrongSecretAtLeast32Bytes
```

### 4.5 Flyway 如何建表

迁移脚本位置：

```
Backend/src/main/resources/db/migration/V1__init_schema.sql
```

**你不需要手动执行这个 SQL。** 后端启动时 Flyway 会自动运行。

建表完成后会有：

| 表名 | 说明 |
|------|------|
| `users` | 用户账号 |
| `memos` | 备忘录 |
| `memo_todos` | 备忘录待办项 |
| `trips` | 出行计划 |
| `trip_checklists` | 出行清单 |
| `photo_libraries` | 照片库 |
| `photos` | 照片元数据 |
| `outbox_events` | 出站事件（异步任务预留） |
| `flyway_schema_history` | Flyway 版本记录 |

### 4.6 数据持久化在哪里

Docker volume `mysql_data` 挂载到 MySQL 数据目录：

- `docker compose down` → **数据保留**
- `docker compose down -v` → **数据全部清空**（慎用）

### 各层职责（新建接口时按这个分层）

| 层级 | 文件类型 | 职责 |
|------|----------|------|
| **Controller** | `*Controller.java` | 接收 HTTP 请求，返回 `ApiResponse` |
| **Service** | `*Service.java` | 业务逻辑、事务 `@Transactional` |
| **Repository** | `*Repository.java` | JPA 数据库 CRUD |
| **Entity** | `*.java` + `@Entity` | 与数据库表字段映射 |
| **DTO** | `*Dtos.java` | 请求/响应数据结构，加校验注解 |
| **Migration** | `V2__xxx.sql` | 新表/改表（Flyway 版本化管理） |

### 配置文件说明

**application.yml**

```yaml
spring:
  profiles:
    active: dev    # 默认使用 dev 配置
server:
  port: 8080       # 后端端口
app:
  jwt:             # JWT 密钥与过期时间
```

**application-dev.yml**

- `spring.datasource.*` → MySQL 连接
- `spring.jpa.hibernate.ddl-auto: validate` → 只校验表结构，不自动改表
- `spring.flyway.enabled: true` → 启动时自动跑迁移
- `spring.redis.*` / `spring.kafka.*` → 缓存与消息队列

## 11. 如何新建一个接口（完整示例）

以下以新增「习惯打卡 Habits」模块为例，演示从数据库到 API 的完整流程。  
**实际开发时可复制 `memo/` 模块改名字。**

### 第 1 步：写 Flyway 迁移脚本

新建文件：

```
Backend/src/main/resources/db/migration/V2__create_habits.sql
```

```sql
CREATE TABLE habits (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT NOT NULL,
    name VARCHAR(64) NOT NULL,
    icon VARCHAR(32) NOT NULL DEFAULT 'star',
    streak INT NOT NULL DEFAULT 0,
    total INT NOT NULL DEFAULT 0,
    target_days INT NOT NULL DEFAULT 30,
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    CONSTRAINT fk_habits_user FOREIGN KEY (user_id) REFERENCES users(id)
);
CREATE INDEX idx_habits_user ON habits(user_id);
```

> 命名规则：`V{版本号}__{描述}.sql`，版本号必须递增。

### 第 2 步：创建 Entity

`Backend/src/main/java/com/allpowerful/backend/habit/Habit.java`

```java
@Entity
@Table(name = "habits")
@Getter @Setter
public class Habit {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(name = "user_id", nullable = false)
    private Long userId;

    @Column(nullable = false, length = 64)
    private String name;

    @Column(nullable = false, length = 32)
    private String icon = "star";

    private Integer streak = 0;
    private Integer total = 0;

    @Column(name = "target_days")
    private Integer targetDays = 30;

    @Column(name = "created_at")
    private LocalDateTime createdAt;

    @Column(name = "updated_at")
    private LocalDateTime updatedAt;
}
```

### 第 3 步：创建 Repository

`HabitRepository.java`

```java
public interface HabitRepository extends JpaRepository<Habit, Long> {

}
```

### 第 4 步：创建 DTO

`HabitDtos.java`

```java
public class HabitDtos {
    public record HabitRequest(
        @NotBlank String name,
        @NotBlank String icon,
        @NotNull Integer targetDays
    ) {}

    public record HabitResponse(
        Long id, String name, String icon,
        Integer streak, Integer total, Integer targetDays
    ) {}
}
```

### 第 5 步：创建 Service

`HabitService.java`

```java
@Service
@RequiredArgsConstructor
public class HabitService {
    private final HabitRepository habitRepository;

    @Transactional(readOnly = true)
    public List<HabitDtos.HabitResponse> list(Long userId) {
        return habitRepository.findByUserIdOrderByUpdatedAtDesc(userId)
            .stream().map(this::toResp).toList();
    }

    @Transactional
    public HabitDtos.HabitResponse create(Long userId, HabitDtos.HabitRequest req) {
        Habit h = new Habit();
        h.setUserId(userId);
        h.setName(req.name());
        h.setIcon(req.icon());
        h.setTargetDays(req.targetDays());
        h.setCreatedAt(LocalDateTime.now());
        h.setUpdatedAt(LocalDateTime.now());
        return toResp(habitRepository.save(h));
    }

    private HabitDtos.HabitResponse toResp(Habit h) {
        return new HabitDtos.HabitResponse(
            h.getId(), h.getName(), h.getIcon(),
            h.getStreak(), h.getTotal(), h.getTargetDays()
        );
    }
}
```

### 第 6 步：创建 Controller

`HabitController.java`

```java
@RestController
@RequestMapping("/api/habits")
@RequiredArgsConstructor
public class HabitController {
    private final HabitService habitService;

    @GetMapping
    public ApiResponse<List<HabitDtos.HabitResponse>> list() {
        return ApiResponse.ok(habitService.list(CurrentUser.id()));
    }

    @PostMapping
    public ApiResponse<HabitDtos.HabitResponse> create(@Valid @RequestBody HabitDtos.HabitRequest req) {
        return ApiResponse.ok(habitService.create(CurrentUser.id(), req));
    }
}
```

### 14.2 基础设施部署

或使用云数据库 RDS（MySQL）替代自建 MySQL，Redis/Kafka 同理。

本地或 CI 中：

```bash

mvn clean package -DskipTests
```

产物：`Backend/target/backend-0.0.1-SNAPSHOT.jar`

创建 `application-prod.yml` 或通过环境变量注入：

```yaml
spring:
  datasource:

    password: <DB_PASSWORD>
  redis:
```

启动：

## 15. 常见问题排查

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| `java: command not found` | 未装 JDK | 按第 3 章安装 JDK 17 |
| `mvn: command not found` | 未装 Maven | `brew install maven` |
| `docker: command not found` | 未装或未启动 Docker Desktop | 安装并打开 Docker |
| 后端启动报 DB 连接失败 | MySQL 未启动 | `docker compose up -d`，等 healthy |
| Flyway 迁移失败 | 库里有旧表/版本冲突 | `docker compose down -v` 重置（会删数据） |
| 3306 端口占用 | 本机已有 MySQL | 停本机 MySQL 或改 docker 端口映射 |
| 前端 401 | token 过期或未登录 | 重新登录 |
| 前端有 mock 数据 | sync 失败或未调用 | 看 Network 请求、Console 报错 |
| Kafka 连接警告 | kafka 容器未 ready | `docker compose ps`，等 kafka 启动 |
| IDEA 依赖全红 | Maven 未刷新 / JDK 不对 | Reload Maven + 设 JDK 17 |
