# 提示词示例

在新对话里 @ 本 skill，或粘贴下面任意一条。

## 最短（推荐）

```
按 login-visual-system 改登录页。
```

## 保效果微调

```
按 login-visual-system：登录页点一下要出正弦水浪，UI 当布跟着弯，按钮和输入框一样透明描边。不要卸 Three.js，不要改文字特效。
```

## 明确禁止回退

```
继续改 LoginView / LoginThreeField / loginWave。遵守 .cursor/skills/login-visual-system。禁止：reduced-motion 卸载 WebGL、标题 shader、主按钮实心填充、UI 用 translate/rotate 冒充形变。
```
